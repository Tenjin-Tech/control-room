# Contributing

Control Room's app code is closed, but this repository is open: bug reports, feature ideas and plugins are welcome here.

## Report a bug

The quickest way is **Feedback** in the app: point at the part that is wrong, say what happened, and Control Room files the issue with its version.

Or [open a bug report](https://github.com/Tenjin-Tech/control-room/issues/new?template=bug.yml). Say what you did, what you expected, what happened instead, and your Control Room and macOS versions. A screenshot helps.

## Propose a feature

[Open a feature request](https://github.com/Tenjin-Tech/control-room/issues/new?template=feature.yml): describe the problem first, then the change you would like. For an open question or an early idea, start a [discussion](https://github.com/Tenjin-Tech/control-room/discussions) instead.

## Propose a plugin

Plugins are listed in [`plugins.json`](plugins.json). See [Add yours](README.md#add-yours) in the README for the steps, and [docs/plugins.md](docs/plugins.md) for the plugin API.

## Labels

- `feedback`: comes from a Control Room user
- `bug`: something does not work
- `enhancement`: a new feature or a change to one
- `ux`: how the app looks, reads or feels
